# Ride-IT-Analysis
●	Performed data profiling, transformation and detailed exploratory analysis of bookings, cancellations, drivers, driver ratings etc.
●	Derived KPI metrics, trend analysis, booking vs cancellations comparison, marketing subscription impact analysis.
●	Identified key factors influencing driver engagement, including weekly active hours and ride acceptance rates, using advanced data analysis techniques.
●	Designed and implemented interactive dashboards to visualize engagement trends, segment performance, and key metrics, facilitating data-driven decision-making for stakeholders
